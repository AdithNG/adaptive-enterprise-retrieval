Cohort Comparator & Trace Linker for Deployment Health

Build a combined Cohort Comparator and Request Trace Linker inside the Console to make canary/A-B/shadow rollouts diagnosable end-to-end. The feature surfaces per-route metric diffs between cohorts, links anomalous metric deltas to sampled request traces, and exposes suggested rollback signals (automated and manual) backed by thresholded telemetry. This is intended to reduce MTTI for rollout regressions and make auto-rollback decisions transparent to product and platform teams.
Comparator UI shows side-by-side cohort-level charts for latency (p50/p95), error rate, token cost, and request throughput for a selected time window
Diff view highlights statistically significant deltas and annotates percentage change with confidence intervals
User can click a diff to see sampled traces from both cohorts with request-level metadata (route, model version, routing policy, input hash)
Trace Linker pins causal spans and shows top 3 signal contributors (e.g., model variant, batch size, region) derived from instrumentation
Auto-rollback triggers are visible per-rollout and can be toggled; Console records the reason and suggested fallback model
All telemetry queries are reproducible (copyable query) and dashboards exportable as PNG/CSV
Feature is behind a Console feature flag and gated to Dedicated/Hosted customers in beta
