Requirements summary (from call notes):
- Workload: agent-assist real-time suggestions (multichannel chat + voice->text), ticket summarization at end-of-interaction, automated tool-calls (order lookup, refund initiation).
- Latency/throughput targets: p95 latency for suggestions < 300ms; batch summarization SLA within 5s; scale target 400 concurrent agents (peak 1200 agents during promos).
- Cost sensitivity: mid-high. Looking for predictable reserved capacity for promos + burst.
- Model preferences: multilingual models with locale-aware tone control, deterministic summarization for compliance, ability to pin model versions. Want explicit fallback routing to larger model variant on confidence threshold.
- Routing/fallback: region-aware routing (EU traffic must prefer EU-resident infra), tiered fallback (small quantized model -> medium -> full-precision).
- Security/compliance: SSO/SAML, audit logs for all token-level actions, KMS-managed keys for model inputs/outputs, data residency for EU/UK, 7-year retention for selected transcripts for legal disputes.
